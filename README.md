# Ремонт и очистка Windows (`WinRepair`)

Современное настольное приложение для **Windows 10 (1809+)** и **Windows 11 (21H2+)** на русском языке для комплексной диагностики, безопасной очистки с предпросмотром и карантином, восстановления системных компонентов ОС и оптимизации ресурсов.

---

## Возможности программы

1. **Комплексная диагностика (строго в режиме чтения):**
   - Расчёт честной оценки состояния системы от **0 до 100** по 10 категориям (без фиктивных проблем).
   - Проверка дисков (свободное место, SSD/HDD/NVMe, статус SMART, температура, целостность NTFS).
   - Проверка хранилища компонентов через `DISM /CheckHealth` и `/ScanHealth`.
   - Анализ критических ошибок Журнала событий Windows за последние 30 дней.
   - Аудит остановленных критичных служб, проблемных драйверов (`Win32_PnPEntity`), сети и DNS, Центра обновления Windows, времени загрузки (UEFI/BIOS), электропитания и защитных механизмов (Microsoft Defender, Брандмауэр, точки восстановления).
   - Кнопка **«Исправить всё безопасное»** на экране «Обзор».

2. **Очистка системы с обязательным предпросмотром (10 модулей):**
   - Каждый модуль реализует строгий цикл `ScanAsync()` → `PreviewAsync()` → `ExecuteAsync()`.
   - Очистка системного мусора (`%TEMP%`, `C:\Windows\Temp`, `Prefetch`), Корзины, кэша обновлений (`SoftwareDistribution\Download`), кэша браузеров (Edge, Chrome, Firefox, Яндекс.Браузер, Opera — без затрагивания паролей и истории), эскизов (`thumbcache_*.db`, `iconcache_*.db`), аварийных дампов (`*.dmp`), кэша шейдеров DirectX/GPU, отчётов WER/CBS, остатков удалённых программ и устаревших пакетов WinSxS (`DISM /StartComponentCleanup`).
   - Встроенный сканер больших файлов и дубликатов (по размеру и `SHA-256`) — работает только в режиме просмотра, удаление выполняется пользователем вручную.

3. **Восстановление работоспособности ОС (9 модулей):**
   - Восстановление системных файлов (`sfc /scannow` с разбором вывода) и хранилища компонентов (`DISM /RestoreHealth` с автопоиском `install.wim`).
   - Сброс сетевого стека (`netsh winsock reset`, `netsh int ip reset`, `ipconfig /flushdns`, сброс прокси).
   - Перерегистрация и перезапуск служб Центра обновления Windows (`BITS`, `wuauserv`, `cryptsvc`, `msiserver`) со сбросом `SoftwareDistribution` и `catroot2`.
   - Восстановление системных ассоциаций файлов, схем электропитания (`powercfg -restoredefaultschemes`), проверка диска (`chkdsk`), восстановление загрузчика (`bcdedit /export`, `bcdboot`, `bootrec`) и управление точками восстановления.

4. **Оптимизация и управление программами:**
   - Управление автозагрузкой (`Run`, `RunOnce`, папки «Автозагрузка»), службами и некритичными задачами Планировщика.
   - Переключение схем питания, визуальных эффектов и честная очистка рабочего набора процессов (`EmptyWorkingSet`).
   - Деинсталляция программ и поиск остатков удалённого ПО с подтверждением и `.reg`-бэкапом.

## Архитектура безопасности

- **Точка восстановления перед изменениями:** `SessionSafetyGuard` автоматически создаёт точку восстановления перед первой изменяющей операцией в сессии. Если создать точку не удалось — операция блокируется с подробным объяснением.
- **Белый список и защита от симлинков (`PathValidator`):** удаление разрешено только внутри явно перечисленных корней `WhitelistPolicy`. Каждый сегмент пути проверяется на `ReparsePoint` (символические ссылки и junction) — выход за пределы разрешённого корня блокируется.
- **Неприкосновенные зоны:** `C:\Windows\System32`, `WinSxS` (кроме штатного `DISM`), загрузочные разделы `EFI`/`Boot`, файлы `pagefile.sys`/`hiberfil.sys`, а также личные папки пользователя (`Documents`, `Desktop`, `Pictures`, `Videos`, `Music`, `Downloads`, `OneDrive`) защищены на уровне ядра.
- **Карантин по умолчанию:** удаляемые файлы перемещаются в `%ProgramData%\WinRepair\Quarantine\<дата>\` с манифестом и хешем `SHA-256`.
- **Двойное подтверждение для высокого риска:** операции `repair.bootloader`, `repair.chkdsk`, `repair.network_stack` и безвозвратное удаление требуют ручного ввода контрольной фразы.
- **Полный журнал и откат:** все операции записываются в `%ProgramData%\WinRepair\Journal\operations.json` и ротируемый лог Serilog `%ProgramData%\WinRepair\Logs\winrepair-.log`.

## Структура решения

```text
WinRepair.sln
├─ WinRepair.Core/            # Чистые модели, интерфейсы, парсеры SFC/DISM, WhitelistPolicy, PathValidator
├─ WinRepair.Services/        # Реализация диагностики, очистки, восстановления, карантина, бэкапов и отчётов
├─ WinRepair.App/             # Настольное приложение WPF (.NET 8, WPF-UI Fluent Design, MVVM) + app.manifest
├─ WinRepair.Tests/           # Модульные тесты xUnit + FluentAssertions
├─ installer/
│  ├─ WinRepair.iss           # Полный скрипт установщика Inno Setup 6 (русская локализация)
│  └─ LICENSE_RU.txt          # Лицензионное соглашение на русском языке
├─ docs/
│  └─ MODULES.md              # Справочник по каждому модулю (команды, API, риск, откат)
└─ build.ps1                  # Автоматический скрипт тестирования, публикации и сборки setup.exe
```

---

## Как запустить тесты

На рабочей станции с установленным **.NET 8 SDK**:

```powershell
dotnet test WinRepair.Tests/WinRepair.Tests.csproj -c Release --verbosity normal
```

## Как собрать автономный исполняемый файл и установщик `setup.exe`

### Вариант 1: Автоматическая сборка через `build.ps1` (рекомендуется)

Требуются **.NET 8 SDK** и **Inno Setup 6** (`ISCC.exe`):

```powershell
.\build.ps1 -Version "1.0.0" -Configuration "Release" -Runtime "win-x64"
```

Скрипт последовательно:
1. Выполнит все модульные тесты `WinRepair.Tests`;
2. Опубликует автономную single-file сборку `publish\win-x64\WinRepair.App.exe` (не требующую установленного .NET у пользователя);
3. Скомпилирует `installer\WinRepair.iss` через `ISCC.exe`;
4. Поместит готовый установщик в `dist\WinRepair-Setup-1.0.0.exe` и `dist\setup.exe`.

### Вариант 2: Ручная публикация single-file приложения

```bash
dotnet publish WinRepair.App -c Release -r win-x64 --self-contained true \
  -p:PublishSingleFile=true -p:IncludeNativeLibrariesForSelfExtract=true \
  -p:EnableCompressionInSingleFile=true
```

### Ключи тихой установки `setup.exe`

- `/SILENT` — тихая установка с отображением только индикатора прогресса;
- `/VERYSILENT` — полностью скрытая установка без окон;
- `/DIR="C:\Program Files\WinRepair"` — выбор пользовательского каталога установки.
